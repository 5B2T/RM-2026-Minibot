# 主控侧机械臂目标角接入说明

更新：2026-10-25。四路位置舵机跟随及控制权切换已完成软件验证；F407已烧录并通过待机校验，中继板尚未更新，未实物联调；底座位置环尚未实现。本地结构限位、方向和动作定义以robot_config.h及arm.c为准。

## 当前能力

链路：输入板F103 → I²C → 中继板F103（电位器/状态机）→ nRF24L01 → F407。

| 电位器通道 | 功能 | 当前车端执行 |
|---|---|---|
| PA0 / target[0] | 底座 | 解码保留，目标模式下电机输出强制为0，等待位置环 |
| PA1 / target[1] | J1大臂 | 10～150°，90°/秒斜坡 |
| PA2 / target[2] | J2小臂 | 23～180°，90°/秒斜坡 |
| PA3 / target[3] | J3俯仰 | 22～270°，90°/秒斜坡 |
| PA4 / target[4] | J4腕旋转 | 0～180°，90°/秒斜坡 |
| 无电位器 | J5夹爪 | SW7切换6°闭合/30°张开，计数去重 |

四路目标同时更新；值超结构范围时钳位。舵机电气量程仍为300/300/270/180/180°，不能用电气量程替代结构限位。J3绝对角度仍为小角度高、大角度低；电位器映射方向应由中继标定表确认，不能把摇杆抬升方向系数再次乘到POS角度。

## 操作及接管

1. 上电前人工摆J1/J2/J3/J4/J5到10°/23°/22°/180°/6°。上电不发定位PWM，位置只是软件假定，不是实测。
2. 遥控器回中校准并使能，电位器稳定300ms后，右上+右下组合键进入目标模式；再次按该组合或右左+右右退出。
3. 进入时取消原有手动/串口/展开动作，从当前软件指令角度沿斜坡到电位器目标，不直接复制为首帧角度。首次启用仍依赖人工摆位，不能保证实际位置和假定位置相同。
4. 目标模式下，右摇杆的底座/关节量与SW6忽略，SW7仍可开合；左手底盘控制保留。底座电位器目标暂不驱动电机。
5. 收到不带目标标志的新控制帧时，先停止一个控制周期，再允许摇杆；遥测V4或两帧之间没有新包不视为退出。
6. STOP、全车失能、通信故障及100ms无线指令超时优先停机。位置舵机保持最后下发PWM，底座关闭，未启用的通道保持无PWM；不是切断舵机供电。
7. 中继在输入失效时立即禁止附加目标字段，并于下次电位器更新清除模式；输入恢复后不会自动重新进入，需重新按组合键。即使状态机暂时仍为ACTIVE也执行此规则。
8. 目标模式移动后，一键动作参考记为UNKNOWN；退出后不能盲目继续SW6。人工恢复初态并重新上电，按既有策略重建假定参考。

目标模式及退出屏障期间不执行串口队列；无线拥有机械臂时拒绝串口运动请求。串口STOP仍可请求停止，不能用串口绕过无线全车锁定。

## 无线格式

V3仍为32字节：A5、03、序号、标志、4个int16控制量、18字节Reserved、CRC16。多字节均小端，CRC覆盖0～29，初值FFFF、多项式A001。

| 字段 | 意义 |
|---|---|
| Flags 0x01 / 0x02 | STOP / RESUME |
| Flags 0x04 | 当前帧包含电位器目标角，限V3普通控制帧，不与STOP/RESUME组合 |
| Reserved[0] | 原摇杆选中关节0～3 |
| Reserved[1..2] | 原摇杆关节速率；目标模式下忽略 |
| Reserved[3] / [4] | 展开/夹爪事件计数器 |
| Reserved[5..14] | 5个int16目标角，顺序为底座/J1/J2/J3/J4，单位 **0.1°** |
| Reserved[15] / [16] / [17] | 必须分别为0x1F / 1 / 0 |

未带0x04时Reserved[5..17]必须全0。原版未更新的解码器会拒收新目标帧；新的车端协议校验已支持目标扩展。

V4是独立只读遥测帧，角度为uint16、单位 **0.01°**，有效范围0～33300，ADC范围0～4095；支持POTS和POT_MODE标志。它只显示电位器数据，不是执行器位置反馈，不使能车辆、不刷新控制指令租约，也不直接控制舵机。

## 车端接口

- `RemoteControl_TakeArmSnapshot()`：在同一临界区读取输入、目标角和链接/STOP代数；只消费按键事件，不消费目标模式有效性。STOP、RESUME、断联及普通帧退出时清除目标有效性。
- `RemoteControl_ArmTargets.TickMs`：真实目标帧接收时刻。控制循环可多次使用同一快照，但不能用读取时刻替代接收时刻延长租约。
- `Arm_FollowTargets(AngleDeg, Gripper, CreatedMs, NowMs)`：验证全部四轴目标后统一更新；按结构范围钳位，继承现有斜坡；底座保持0，不操作夹爪，除非收到新的Gripper事件。
- `ArmControlStep()`：STOP → 有效目标模式 → 目标模式退出屏障 → 原摇杆 → 无线退出 → 串口队列。
- `Arm_Status.Action == ARM_FOLLOW`（值8）表示当前跟随。未改变ARMDBG V2、25列串口布局或V3包长，也未更改既有动作枚举值。

## 标定与后续

中继默认ADC映射及软限位仍是初始值，尚未与新结构逐轴标定；应按实际电位器端点、安装方向和机械坐标调整ArmController/UserApp/arm_targets.c的DefaultCal。车端继续独立执行更严格的结构限位；靠钳位运行会出现电位器部分行程不响应，不能当作标定完成。

底座速度PI已带载整定并烧录，RATE ±1对应±3.5RPM，输出上限300，Kp22/Ki80/Kd0。底座6600计数/圈尚待实测；电位器333°不等于底座机械行程。编码器极性已校正为-1，空载速度PI及无计数/反向反馈保护已实现；仍需确认每圈计数、相对零位和可用行程后再接位置环。原建议Kp=8、死区1°、PWM斜率600/s、±165°尚未采用。

## 验证与部署

本机原生GCC加入PATH后，在仓库根目录执行：

```powershell
./tools/run_arm_follow_tests.ps1
gcc -std=c11 -Wall -Wextra -Werror -I Modules tools/test_pot_protocol.c Modules/command/command_protocol.c Modules/command/telemetry_protocol.c -o build/test_pot_protocol.exe
./build/test_pot_protocol.exe
```

测试使用真实车端调度、接收、机械臂及舵机换算代码，硬件输出和无关模块由主机桩代替；覆盖四轴斜坡/限位、夹爪计数、缓存目标有效期、模式退出屏障、串口/展开仲裁、STOP/断联/超时、旧展开收起顺序、CPU计时回绕和硬件失败。中继目标模块测试覆盖输入失效、恢复不自动重入、锁定/ADC失效和组合键退出。

实物使用需要F407与中继板均更新到匹配版本；本轮不要求重刷输入板。F407已烧录，中继板待换接烧录；联调前重新核对人工初态和电位器标定；先断动力或固定机械臂逐轴低行程验证，再验证整套动作。
