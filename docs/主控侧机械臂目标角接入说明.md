## 通信恢复自动接管（2026-10-28，软件更新、待烧录中继）

本节替代下文“通信恢复后必须重新使能/重新进入POT”和“输入失效200ms后退出POT”的旧规则。初次上电仍需手动使能、右摇杆按压选择POT；已经使能后，无线80ms无应答或连续3次发送失败仅暂停控制，保留使能授权与POT选择，中继自动发送零运动RESUME握手。车端100ms收包超时仍停止底盘及手动底座/关节，位置舵机保持当前指令；收到恢复握手并应答后，按最新控制值自动继续，POT目标仍限速，不重放断联前的运动帧或展开/夹爪按键事件。恢复后控制杆与机械臂位置不同时会按限速追随当前目标。

输入板通信或整组ADC采集失效时，已选POT暂停输出并保留选择；恢复有效输入后自动继续。单路ADC到0/4095仍保持该轴最后有效目标。主动失能、明确停止或内部错误锁定仍需人工重新使能，主动失能清除POT选择；初始使能失败不会自动放行。已启动自动展开/收起的离线继续策略不变，主控重启后仍须重新确认初始姿态。

仅需更新接nRF和电位器的中继ArmController；F407沿用现有RESUME接口，输入板无需重刷。V3/V4帧及POTRAW格式不变，中继每秒状态行末尾新增REC=1表示正在自动恢复、REC=0表示非恢复状态。MODE=2是保留使能授权，恢复中不等于正在输出；LOCK/N保留最近通信故障记录，并不表示此刻必须手动解锁。实物断联/恢复待验证。

## 自动序列与断联（2026-10-28最新，F407及中继已部署、待实测）

无线拥有的已启动展开/收起，在无线超时、接收模块重连及中继被动锁定期间继续本地执行；只保留这一次有限序列，不接受离线新动作。底盘、手动底座/关节及POT跟随仍停机。重连RESUME不取消、重启序列，旧按键计数不重放；收到主动STOP、串口STOP或本地反馈/超时故障仍停止。

V3增加PASSIVE_STOP标志0x08，仅允许与STOP组合为0x09，且禁止与RESUME/ARM_TARGETS混用，保留CRC校验。主动STOP仍0x01；旧STOP继续按主动停止处理。中继的ExplicitStop独立于LastLockReason，避免先因断联锁定后按失能仍被误标为被动停止。接收端分别记录所有STOP代数与ExplicitStopGeneration：底盘尊重全部STOP，机械臂自动序列只豁免被动停止/租约失效；同一控制周期的后续被动帧不能覆盖已收到的主动停止。

需要同时更新F407和中继；输入板、无线32字节尺寸、V4及ARMDBG V2不变。下方“100ms租约保留”现仅对手动和POT直接停机，自动序列按本节执行。其余阈值与反馈、限位、有限时长保护保持，不为追求不中断而忽略真实执行器故障。

## 当前恢复策略（2026-10-28，F407及中继已部署、待实测）

本节优先于下方历史操作说明；V3被动STOP标志以最上方最新说明为准，V4、25列ARMDBG V2串口及既有标定表不变。需更新F407和中继，输入板不用更新。

底座目标模式改为显式按键授权后，从当前编码器位置以原90°/秒上限斜坡接管，取消3°等待窗口，±180°目标限位及不作360°回绕规则保留。首次切入时目标相差很大会实际追踪，操作前留出空间。五路有效且稳定100ms后进入；进入请求3秒过期。模式内整组ADC采集或输入桥接短暂失效，最多200ms保持原目标，持续异常则退出且不自动重入；单路原始ADC越界仍保持该路。

可恢复故障通过“失能、回中、停稳、重新使能”的新RESUME握手确认，不增加无线字段。确认仅在停稳、无动作时执行，最多等待2秒，不修改编码器计数、ZeroGeneration或关节软件角度，不恢复缓存目标。运行期输出外设失败可尝试重新初始化零PWM，重新初始化失败则保持故障；编码器持续被动采样。启动参考未建立或CPU严重异常不走此恢复入口。

串口调试停止与无线所有权分离：格式/范围错误、UART错误、应答队列拥塞、心跳300ms超时只取消调试会话自己的动作，`ERR BUSY`只拒绝请求。明确`ARM STOP`仍全局停止机械臂；全车无线失能和100ms命令租约保留。底座无反馈/反向锁存与停止确认保留；没有增加遥控置零。

MAX_RT单次丢包仅丢弃旧包，下个20ms周期发送最新控制帧；连续3次控制TX失败或80ms ACK超时锁定。SPI/配置等真实硬件错误仍重新初始化模块。自动动作仅在手动偏转达到25%并持续200ms后接管，明确失能不延迟。机械限位、位置回差、速度、换向间隔、回零/序列超时不变。

## 操作及接管

1. 上电前人工摆J1/J2/J3/J4/J5到5°/23°/22°/90°/6°。上电不发定位PWM，位置只是软件假定，不是实测。
2. 遥控器回中校准并使能，电位器稳定300ms后，右摇杆按压PC15进入目标模式；再次按压或右左+右右退出。
3. 进入时取消原有手动/串口/展开动作，从当前软件指令角度沿斜坡到电位器目标，不直接复制为首帧角度。首次启用仍依赖人工摆位，不能保证实际位置和假定位置相同。
4. 目标模式下，右摇杆的底座/关节量与SW6忽略，SW7仍可开合；左手底盘控制保留。底座最初保持停止，电位器目标与编码器当前角度相差≤3°且转速≤0.4RPM才接管；退出/STOP/断联后必须重新对齐。
5. 收到不带目标标志的新控制帧时，先停止一个控制周期，再允许摇杆；遥测V4或两帧之间没有新包不视为退出。
6. STOP、全车失能、通信故障及100ms无线指令超时优先停机。位置舵机保持最后下发PWM，底座关闭，未启用的通道保持无PWM；不是切断舵机供电。
7. 中继在输入失效时立即禁止附加目标字段，并于下次电位器更新清除模式；输入恢复后不会自动重新进入，需重新按右摇杆。即使状态机暂时仍为ACTIVE也执行此规则。
8. 目标模式移动后姿态记UNKNOWN但软件指令角度和底座零点保留；退出后SW6先从当前角度重新收起，不继续旧阶段。只有重启或人工搬动后仍需恢复初态。

目标模式及退出屏障期间不执行串口队列；无线拥有机械臂时拒绝串口运动请求。串口STOP仍可请求停止，不能用串口绕过无线全车锁定。

## 无线格式

V3仍为32字节：A5、03、序号、标志、4个int16控制量、18字节Reserved、CRC16。多字节均小端，CRC覆盖0～29，初值FFFF、多项式A001。

| 字段 | 意义 |
|---|---|
| Flags 0x01 / 0x02 | STOP / RESUME |
| Flags 0x04 | 当前帧包含电位器目标角，限V3普通控制帧，不与STOP/RESUME组合 |
| Reserved[0] | 原摇杆选中关节0～3 |
| Reserved[1..2] | 原摇杆关节速率；目标模式下忽略 |
| Reserved[3] / [4] | 展开/夹爪事件计数器 |
| Reserved[5..14] | 5个int16目标角，顺序为底座/J1/J2/J3/J4，单位 **0.1°**；底座为相对人工零位的有符号角度 |
| Reserved[15] / [16] / [17] | 必须分别为0x1F / 1 / 0 |

未带0x04时Reserved[5..17]必须全0。原版未更新的解码器会拒收新目标帧；新的车端协议校验已支持目标扩展。

V4是独立只读遥测帧，角度为uint16、单位 **0.01°**，有效范围0～33300，ADC范围0～4095；支持POTS和POT_MODE标志。底座V4显示值为其标定区间归一化后的0～333°（中点166.5°），不等于有符号底座目标；目标值见V3或中继POTRAW/ANG。它只显示电位器数据，不是执行器位置反馈，不使能车辆、不刷新控制指令租约，也不直接控制舵机。

## 车端接口

- `RemoteControl_TakeArmSnapshot()`：在同一临界区读取输入、目标角和链接/STOP代数；只消费按键事件，不消费目标模式有效性。STOP、RESUME、断联及普通帧退出时清除目标有效性。
- `RemoteControl_ArmTargets.TickMs`：真实目标帧接收时刻。控制循环可多次使用同一快照，但不能用读取时刻替代接收时刻延长租约。
- `Arm_FollowTargets(AngleDeg, Gripper, CreatedMs, NowMs)`：验证五轴目标后统一更新；J1～J4按结构范围钳位并斜坡跟随，底座经对齐接管后执行相对位置闭环；夹爪只响应新Gripper事件。
- `ArmControlStep()`：STOP → 有效目标模式 → 目标模式退出屏障 → 原摇杆 → 无线退出 → 串口队列。
- `Arm_Status.Action == ARM_FOLLOW`（值8）表示当前跟随。未改变ARMDBG V2、25列串口布局或V3包长，也未更改既有动作枚举值。

### 右摇杆按压切换（2026-10-27）

输入板采集PC15低有效按键，通过原I²C帧KEY_R_PRESS位转发；中继不再屏蔽此位。使能后按一下进入、再按退出，原上+下入口取消，左+右保留退出。进入请求最多等待1500ms达到ADC有效及稳定300ms；锁定、输入失效、转换失败、再次按压或退出组合键会取消。超时后需新的按压，不会自动重入。输入板、中继均需更新，F407及V3/V4格式不变。中继每秒状态行增加STABLE/WAIT/BLOCK，数值见遥控器操作说明。

### 2026-10-28 动作与结构更新

当前上电假定姿态5/23/22/90/6°，底座人工置于原零位后上电。大臂限位5～150°，夹爪6～45°，其余机械限位不变，尤其J3仍22～270°。展开：J1到95°，再J2/J3/J4同时到103/190/0°，最后夹爪到45°。收起：J3到22°、腕部到0°、夹爪到6°、底座到上电零位同时启动；完成后J2到23°，再腕部到90°，最后J1到5°。首阶段等待底座先进入实测误差≤1°的到位状态，随后保持范围≤2°且测速≤0.4RPM；12秒回零超时或反馈故障中断。不会清零编码器来假定已归位，底座零位代数保持不变。SW6/ARM INIT和无线/25列串口格式不变，原UNKNOWN参考保护保留。F407和中继待更新，输入板不需更新。

### 输入板掉线与自动序列（2026-10-28最新策略）

用户确认接触不良并要求不打断主控自动动作。中继ACTIVE状态取消原200ms输入失效锁定：输入无效时发送普通V3零运动量帧，保留原展开/夹爪事件计数，不伪造STOP，不刷新或重放事件；因此已启动的主控自动序列继续执行。恢复数据时重新建立按键基线，长按跨恢复不算新动作；偏转摇杆可恢复运动。POT模式仍随输入失效退出，不持有旧电位器跟随目标。未使能不自动进入ACTIVE，RESUMING输入无效仍锁定；显式失能、RF失败/应答超时、主控命令租约均保持。只更新中继，F407和输入板不变。输入线断开时按键停止不可达，操作须具备直接断动力电源手段。
