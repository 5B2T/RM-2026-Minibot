# 遥控器操作说明

更新：2026-10-22。双F103：输入板采集摇杆/按键，经I²C送中继板，再由nRF24L01发送无线V3到F407。不接遥控OLED，不使用摇杆按压。

用户已修复J3自转问题，未烧录的临时隔离补丁已撤销；J3正常参与角度控制，编号及操作不变。

| 操作 | 功能 |
|---|---|
| 左摇杆 | 底盘全向平移，最大0.54m/s，回中停止 |
| 左上PA11 / 左下PA12 | 全车使能 / 全车停止锁定；使能需两摇杆回中且其他键松开 |
| 左侧左/右键 | 按住逆时针/顺时针转向，最大1.8rad/s |
| 右摇杆左右 | 底座电机正反转，最大约30%PWM，回中停止 |
| 右侧上/下/左/右键 | 选J1大臂/J2小臂/J3夹爪俯仰/J4腕旋转；切换后需右摇杆上下回中 |
| 右摇杆上下 | 对选中关节增减角度，满杆名义90°/s；J1/J2上推增角抬升；J3上推减角抬升、下推增角降低；J4上推增角；回中保持已下发角度 |
| SW5 | 硬件复位，重启保持锁定 |
| SW6 | 短按大臂先行、后三轴同时展开、最后张开夹爪；再按先J3回收+夹爪闭合，随后J4→J2→J1；右摇杆需回中，运行中重复按忽略 |
| SW7 | 夹爪0°闭合/30°张开切换，首次选择张开；收到的重复帧不重复切换 |

改造后五路全为位置舵机：J1/J2 JX6225名义300°，J3 MG90D 270°，J4/J5 MG90S 180°。旧J1偏移零点、旧0～150°限位、J2/J3连续旋转定时估角、夹爪0/45°端点均停用。用户最新确认J1原方向正确，恢复+1：0/300°对应500/2500μs，上推增角为期望升起方向；PWM方向系数均+1。新机械软限位：J1 10～150°，J2 23～180°，J3 13～270°（高位13°、低位270°），J4 0～180°，J5 0～30°（闭合0°、张开30°）。J3单独反转点动方向，不反转其POS角度换算。到边界保持，推反方向即可离开。

上电前人工摆J1=10°、J2=23°、J3=13°、J4=180°、夹爪0°闭合；软件按此建立假定初态，上电五路无定位PWM，不主动归位。首次展开大臂先到90°，再让小臂/俯仰/腕部同时到103°/270°/0°，收起依次J3→13°、J2→23°、J4→180°、J1→10°。展开最后单独张开夹爪30°；收起首步同步俯仰回13°与夹爪闭合0°，两者软件完成后先收小臂，再转腕部。序列中SW7忽略。标准初态名义展开4.69s、收起7.44s（90°/s及200ms余量），无实际到位反馈。中途停止/断联/手动接管后参考未知，人工摆回初态并重新上电；禁止盲目继续。

两块F103上电保持摇杆/按键松开，等待约0.5秒回中校准，再使能。左下PA12、无线故障使底盘/底座停止，位置舵机保持PWM，不是切断供电。无线恢复后须回中并重新按使能。

沿用master的输入容错：I²C数据60ms未更新变无效，失效期间下发零速；短暂恢复可在ACTIVE状态继续控制，连续无效200ms才锁定。使能恢复阶段输入无效立即锁定；无线发送失败/应答超时仍锁定。短暂输入恢复和无线重新使能是两种情况，前者可能在摇杆仍偏转时恢复运动。

中继串口LOCK/N记录失能首因/次数：0启动、1失能键、2输入失效、3无线发送失败、4无线应答超时、5恢复超时、6恢复时未回中、7内部错误。绿灯只代表I²C应答，车端OLED查看LINK/ARMED。

本轮仅F407舵机业务/串口回传变更，双F103固件及V3帧格式不变，不需因更换舵机而重刷遥控。SW7按新0/30°端点恢复；SW6使用大臂先行、后三轴并行、最后夹爪张开；收起J3+夹爪闭合、J2、J4、J1。
