# 遥控器操作说明

更新：2026-10-17。遥控器采用双F103：RemoteController采集输入，经I²C发送给ArmController，再由后者通过nRF24L01发送整车V3控制帧。软件验证通过，完整实物链路尚未联调。不接遥控器OLED，不使用两个摇杆按压，不设手动置零键。

| 操作 | 功能 |
|---|---|
| 左摇杆前后／左右 | 底盘全向平移，可斜向移动；推得越远越快，回中停止平移；最大0.54 m/s |
| 左侧上键（PA11） | 全车使能／停止后重新使能；需两摇杆回中、其他操作键松开且无线有应答 |
| 左侧下键（PA12） | 全车立即停止并锁定；松开不自动恢复 |
| 左侧左／右键 | 按住逆时针／顺时针转向，缓启动至1.8 rad/s；松开或两键同按停止转向 |
| 右摇杆左右 | 机械臂底座正反转，回中停止；可与选中关节、底盘同时操作 |
| 右摇杆上下 | 控制选中关节正反运动，回中停止；上推为正向、下推为负向（PA6/ADC3方向已按实测反转） |
| 右侧上／下／左／右键 | 分别选中大臂J1／小臂J2／夹爪俯仰J3／腕部旋转J4，默认J1；切换后需右摇杆上下回中，才允许新关节运动 |
| SW5（RESET） | 遥控器硬件复位，保留原接线；重启后保持锁定 |
| SW6（WAUP） | 短按展开，再按收缩；触发时右摇杆需回中；运行中重复按忽略 |
| SW7（KEY_1） | 短按夹爪开合切换：0°闭合／45°张开；可与手动关节、底座动作并行，自动展开／收缩期间忽略 |

1. 上电前人工摆好统一初始姿态：J1新0°、夹爪闭合、J2/J3约定零位；J4按现有90°参考摆放。车端上电建立软件参考，不自动展开，位置舵机首次操作前不输出定位脉冲。
2. 两块F103上电时松开两摇杆及按键，等待约0.5秒完成摇杆回中校准。遥控板绿灯仅表示I²C事务有应答，不表示无线在线；蓝灯暂不绑定。第二块F103串口ACK表示无线应答，MODE=2表示本地允许发送运动，J=1～4表示选中关节；车端OLED查看LINK/ARMED。
3. 按左侧上键使能后操作。J1使用新0～150°坐标，J2正向向上、最大RATE为0.15，J3最大RATE为0.14，J4为0～180°；摇杆可小幅微调，底座最大PWM为30%。
4. SW6展开按顺序执行：J1到新90°，J2向上约90°，J3反转约270°，夹爪张开45°；收缩按相反顺序：夹爪闭合0°、J3返回约270°、J2返回约90°、J1回新0°。每次只运行一个阶段，完成后才进入下一阶段，初始零位出发单程约4.4秒。手动微调后按累计开环估算位置补偿连续关节的返回时间，不能保证精确返零。
5. 左侧下键、断联或输入异常会停止底盘、底座、连续舵机及自动动作；已经启用的角度舵机保持最后下发位置。恢复连接不自动使能，需回中后重新按左侧上键。
6. 自动动作中途被停止或被右摇杆手动接管后，参考状态未知，不允许直接继续展开／收缩；人工摆回初始姿态后重启车端。没有遥控置零键或长按置零功能。

连续舵机没有角度反馈：J2按满量约90°/s、J3约180°/s估算，小指令暂按比例估算；负载、供电和正反转差异会造成误差。摇杆轴向和底座转向仍需首次实物联调确认。

按2026-10-17最新现场反馈，左摇杆输入已纠正90°错位：PA1/ADC0增加为前进，PA2/ADC1增加为左移，右手映射不变；左上/下键已按实测交换为PA11/PA12。此轮三板修改均已烧录校验，待现场复核方向、按键及夹持效果。

夹爪已还原前一版：SW7按当前目标在0°闭合/45°张开间切换，删除新增的独立开合锁存和专用数值钳位；恢复原有位置校验。到位后仍按原版持续输出50Hz定位PWM（0°=500μs，45°=1000μs），不增加到位后释放。STOP冻结在最后下发位置；如果停在中间，下一次SW7按原版规则选择张开45°。软件没有实际机械角度反馈，持续定位不等于夹持力闭环或机械硬限位。

中继板串口新增LOCK（最近一次失能的首个原因）和N（失能次数）：1=失能键、2=输入失效、3=无线发送失败、4=无线应答超时、5=恢复超时、6=恢复时操作未回中、7=内部命令错误，0为启动初始值。原因保留到下一次新的失能事件，不会被锁定后的重试覆盖；这些是诊断信息。夹爪动作后若全车失能，请记录LOCK及车端OLED是否重启，避免误判为角度保护。

双F103分别烧录RemoteController和ArmController固件，车端使用此前已烧录的整车V3版本。双板接线参见[双芯片控制器接线与测试](双芯片控制器接线与测试.md)。I²C断线会锁定，接回后必须松开再重新按使能，不能一直按住等待自动解锁。电位器仅串口输出原始采样，不参与本方案控制或无线发送。

使用遥控时关闭上位机自动发送；车端收到无线控制后，串口及车端测试页不能绕过全车锁定，串口不能抢占遥控中的机械臂。单独车端测试或串口调试时保持遥控器关闭，并重启车端；原ARM ZERO串口调试接口保留。

本轮已更新F407：展开/回收恢复四阶段顺序，夹爪还原前版，已烧录校验并读回待机；两块F103不变。未自动执行机械臂动作，实际效果待复核。
