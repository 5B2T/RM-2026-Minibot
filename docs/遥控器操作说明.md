# 遥控器操作说明

更新：2026-10-05。当前已实现底盘发送、启停和显示；尚未上板联调，摇杆方向及侧键位置待实物确认。

| 操作 | 功能 |
|---|---|
| 电源开关 | 开关遥控器；每次开机默认锁定 |
| 左摇杆前后／左右 | 底盘前后／横移，可斜向移动；推得越远越快，回中停止平移 |
| 左侧左／右键 | 按住缓启动左转／右转，松开停止旋转；同时按下不旋转 |
| 左侧上／下键 | 提高／降低速度档位：低速0.2、中速0.35、标准0.5 m/s；默认低速，摇杆回中且动作键松开时可调整 |
| 左摇杆按压 | 切换OLED页面：状态、输入检查、机械臂输入预览 |
| 侧键KEY_1（SW7） | 急停并锁定；松开不会自动恢复 |
| 侧键WAUP（SW6） | 解锁／恢复；要求两摇杆回中、其他按键全部松开且无线已有应答 |
| 侧键RESET（SW5） | 重启遥控器；正常停车请用急停键 |
| 右摇杆、右侧四键 | 预留夹爪前后／左右、升降和开合；当前仅检查输入，不发送机械臂动作 |
| 右摇杆按压 | 暂未分配功能 |

1. 开机时松开所有按键和摇杆，等待输入状态显示READY、无线应答显示YES。
2. 按一次WAUP恢复，确认本地发送状态为ACTIVE后操作左手控制底盘。
3. 急停、通信异常或输入异常后保持锁定；连接恢复不会自动解锁，需松开按键、摇杆回中，再重新按WAUP。

OLED的ACK表示无线应答，ACTIVE表示遥控端允许发送运动命令，均不代表车端已执行；车辆实际状态查看车端OLED。SUPPLY为遥控器供电电压，当前不显示电量百分比。
