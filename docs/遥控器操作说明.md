# 遥控器操作说明

## 无线失联时的自动动作（2026-10-28最新，F407及中继已烧录、待实测）

已启动的一键展开/收起由车端继续执行到完成，不因无线100ms超时、遥控重启或通信故障锁定而取消；不会新启动或重复动作。底盘、底座手动转动、关节点动和电位器跟随仍在失联后停止，恢复通信后须重新使能，不重放旧指令。序列中重新使能不会重启或插入停止步骤。

收到主动失能键指令或明确的串口`ARM STOP`仍立即终止序列；无线完全断开期间按键指令无法送达车端。编码器反馈故障、机械限位、输出限制及回零12秒/总序列20秒超时保留，不因离线而忽略。

本轮需匹配更新F407和中继，输入板不用更新。中继以V3标志0x08区分被动STOP（总标志0x09）和主动STOP（0x01）；用户在通信锁定后再按失能，仍升级为主动STOP，即使诊断首因仍显示通信故障。V3帧长度/CRC、V4遥测及上位机25列格式不变；旧版STOP按主动停止处理。

## 2026-10-28 当前恢复与接管操作（F407及中继已烧录、待实测）

本节替代下文历史版本的3°对齐接管、300ms稳定/1.5秒入口等待及单次无线发送失败锁定规则。需更新F407和中继板，摇杆按键输入板无需更新。

- 故障恢复：先按左下PA12失能，摇杆回中并等底座停稳，再按左上PA11使能。新的使能握手可清除可恢复的机械臂/底座故障；若反馈仍在运动，最多等待2秒。保留底座上电零点和软件关节角度，不自动续跑旧动作；未恢复时先检查故障原因，再重复此操作。不能恢复CPU硬故障或上电初始化失败。
- 电位器：使能后按右摇杆进入，再按退出。五路有效且稳定100ms即可进入，按键请求最多等待3秒。底座不再等待3°对齐窗口，进入即从当前编码器位置限速追踪目标，最大仍90°/秒；进入前留出运动空间，控制杆与车端尽量接近。
- 模式内短暂输入桥接或整组ADC采集异常：保持上一组目标，持续200ms才退出；恢复后需重新按键进入。单路ADC越界仍仅保持该路目标。锁定/失能立即退出，不等待200ms。
- 无线：单次发射重试耗尽后下一周期发送最新命令，不等待500ms重初始化；连续3次控制发送失败或80ms无控制ACK仍锁定。车端100ms有效命令超时停机不变。
- 自动展开/收起：右摇杆偏置不超过15%时允许触发；运行中轻微误碰不打断，某轴偏转达到25%并持续200ms才手动接管。失能键始终立即生效；重复SW6不重启动作，SW7在序列内仍忽略。
- 串口普通错误、忙状态、回复拥塞和调试心跳超时只停止串口自己接管的动作，不再打断无线控制；明确的`ARM STOP`仍可停止机械臂。

机械限位、底座位置目标±180°、回零12秒/序列20秒、反馈故障锁存、输出/速度限制及换向等待保留。CPU严重异常新增底盘/底座PWM清零与STBY关闭，舵机保留最后定位脉冲；不自动重启、重置零点或恢复运动。

## 电位器目标模式

车端与控制杆姿态先对齐。全车使能后，短按右摇杆（PC15）进入，再按退出；原右侧上+下组合键不再进入，右侧左+右仍可退出。五路ADC有效且稳定300ms才接管；按压后最多等待1.5秒，超时需重新按，不会无限等待后突然进入。锁定、输入失效会取消请求，恢复后必须重新按。不要一边按使能一边按摇杆。

PA0底座、PA1大臂、PA2小臂、PA3俯仰、PA4腕部；夹爪不参与电位器映射，SW7仍开合。目标模式下忽略SW6和右摇杆方向量，左手底盘控制保留。退出先停止一个控制周期再交还摇杆；全车失能和断联保护不变。

上电前底座人工对齐零位，机械臂初态5°/23°/22°/90°/6°。车端底座目标范围±180°、上限90°/秒；接管要求目标与当前底座相差≤3°且测速≤0.4RPM。底座控制杆实测ADC2044为零、3105为逆时针约90°，可用行程估计约±173°；根据现场反向反馈，电位器映射已反转：控制杆逆时针90°发送车端目标-90°；电机及编码器闭环方向不变，改后同向性待复测。腕部零位ADC2243、约90°为3235，可用行程约0～168°。其他参考点见主控侧接入说明，均为人工姿态粗标定。

进入时五路都必须有效（ADC1～4094）；小臂折叠处ADC0不能进入。进入后单路越界只保持该路上一目标，恢复有效再斜坡更新。通信或ADC转换失败仍退出，不用保持策略掩盖通信故障。车端POT页WAIT/RUN/HOLD表示底座对齐/运行/到位。

中继串口POTRAW/ANG每秒20帧；每秒状态行增加STABLE、WAIT和BLOCK：BLOCK=0就绪，1未使能，2输入无效，3电位器ADC无效，4等待稳定，5请求超时。WAIT=1表示进入请求正在等待；POT=1才表示已进入。V4底座0～333°为归一化显示，不是实际底座角度。
