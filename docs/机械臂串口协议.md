# 机械臂串口联调（ARMDBG V1）

## 接线与连接

| J-Link VCOM | F407 | 说明 |
|---|---|---|
| TX | PA10 / USART1_RX | 3.3V TTL |
| RX | PA9 / USART1_TX | 3.3V TTL |
| GND | GND | 共地 |

保留 SWD 接线。上位机选对应 COM 口，115200 baud、8N1、无流控。一个 COM 口同一时间只由一个程序打开。车端须烧录包含本协议的新固件。

## 命令

ASCII、区分大小写、空格分隔，以实际 LF 或 CRLF 结束；每行最多95字节，不含行尾。无CRC，通过行边界、严格字段/范围检查及超时保护接收。数字使用英文小数点。仅控制机械臂，不控制底盘。

| 指令 | 含义 | 示例 |
|---|---|---|
| `ARM ENABLE` | 使能串口调试，不触发运动 | `ARM ENABLE` |
| `ARM HB` | 心跳，不续期单条运动命令 | 每100ms发送一次 |
| `ARM DISABLE` | 取消使能并停止 | `ARM DISABLE` |
| `ARM STOP` | 停止当前动作，保留调试使能 | `ARM STOP` |
| `ARM POS joint deg ms` | 位置舵机目标角度 | `ARM POS 0 150 1000` |
| `ARM RATE joint rate ms` | 单关节正反向控制，rate为-1～1 | `ARM RATE 1 0.05 200` |
| `ARM NEUTRAL joint us` | 连续舵机中立脉宽，仅RAM生效，自动停其他动作 | `ARM NEUTRAL 1 1500` |
| `ARM PRESET ms` | 三个位置舵机返回初始预设，其他关节停止 | `ARM PRESET 3000` |
| `ARM STATUS` | 请求一帧状态 | `ARM STATUS` |
| `ARM STREAM ms` | 设置状态周期：50～1000ms，0关闭；默认100ms | `ARM STREAM 100` |

运动时长为1～5000ms；位置运动以90°/s限速，时长不足会停在途中。每次运动只控制选定关节，切换命令会停止前一动作。位置舵机停止后保持已下发姿态；连续舵机回中立脉宽，基座PWM归零。ENABLE后300ms内必须收到HB或成功接收的运动/中立标定指令，超时取消使能并停止；STATUS/STREAM/STOP不续期。HB不会自动延长POS/RATE/PRESET的时长。

格式错误、非法范围、行超长/嵌入控制字符、未完成行超时、UART错误或收发拥塞会停止并取消使能；恢复时先补一个换行以同步行边界，再ENABLE。停止命令通过控制任务执行，正常响应为下一个10ms周期。

| joint | 关节 | POS | RATE | NEUTRAL |
|---|---|---|---|---|
| 0 | 大臂 | 0～295° | -1～1，对应±90°/s | 不支持 |
| 1 | 小臂 | 不支持 | 连续旋转正反转 | 500～2500μs整数 |
| 2 | 夹爪俯仰 | 不支持 | 连续旋转正反转 | 500～2500μs整数 |
| 3 | 腕部旋转 | 0～180° | -1～1，对应±90°/s | 不支持 |
| 4 | 夹爪开合 | 0～180° | -1～1，对应±90°/s | 不支持 |
| 5 | 基座 | 尚不支持位置闭环 | 开环PWM，rate×300 | 不支持 |

五路舵机为50Hz、500～2500μs；连续舵机默认中立1500μs，中立微调建议从附近小步调整。NEUTRAL不写Flash，重启恢复默认。基座每转6600计数暂定，角度比例/正方向待标定。PRESET预设为大臂147.5°、腕部旋转90°、夹爪90°，不代表整臂自动折叠或基座回零。

## 应答及状态回传

文本应答为单独一行，不含逗号：`HELLO ARMDBG V1`、`OK ENABLE`、`OK DISABLE`、`OK STOP`、`OK STATUS`、`OK STREAM`、`OK QUEUED`；正常HB无应答。`OK QUEUED`仅代表命令进入任务邮箱，不代表动作完成。`ERR BUSY`表示停止优先/未能入队，等待一个控制周期后重试；其他ERR如SYNTAX、RANGE、DISABLED、TIMEOUT、UART、LINE、LINE_TIMEOUT、NOT_READY、TX_OVERFLOW按错误处理。

状态为固定24列纯数字CSV，以CRLF结束，使用Lissio/VOFA的FireWater引擎。Raw Data窗口查看文本应答；应答行不会构成数字波形。每帧如下，通道从0开始：

| 通道 | 字段 | 单位/含义 |
|---|---|---|
| 0 | tick_ms | 控制状态时间戳，uint32回绕 |
| 1～3 | debug_enabled、ready、active | 0/1；ready仅代表软件初始化 |
| 4 | fault | 0正常、1命令到期、2非法命令、3采样异常、4硬件错误 |
| 5～6 | joint、action | joint如上；action：0停止、1预设、2位置、3速率、4中立标定 |
| 7～9 | shoulder_mdeg、roll_mdeg、gripper_mdeg | 下发角度×1000，非实测角度 |
| 10～11 | elbow_rate_milli、pitch_rate_milli | 归一化速率×1000 |
| 12～16 | shoulder_us、elbow_us、pitch_us、roll_us、gripper_us | 五路实际下发脉宽μs |
| 17 | base_counts | 本次初始化以来的相对编码器计数，有符号整数 |
| 18～19 | base_mdeg、base_mrpm | 相对角度、转速，各×1000 |
| 20 | base_pwm | -300～300，TB6612方向与占空比 |
| 21～23 | uart_faults、commands、errors | UART异常计数、语法正确指令数、拒绝/接收错误数 |

连续舵机无角度反馈，无法保存并复现其角度限位；基座相对零点重启后变化。波形浮点解析可能降低大计数精度，精确记录使用原始CSV。

## 上位机绑定及记录

Lissio中添加Serial数据接口及FireWater协议，设24通道，连接波形。命令发送器发送ASCII，并确保追加真实换行。控件使用Manual文本发送，不能用自动浮点发送替代命令；源码版本支持`{value}`替换，安装的0.7.2版以实际控件功能为准。

| 控件 | 发送内容（末尾追加LF） |
|---|---|
| 使能/停止/取消使能按钮 | `ARM ENABLE` / `ARM STOP` / `ARM DISABLE` |
| 心跳循环发送，100ms | `ARM HB` |
| 大臂角度滑条，0～295 | `ARM POS 0 {value} 1000` |
| 腕部旋转/夹爪滑条，0～180 | `ARM POS 3 {value} 1000` / `ARM POS 4 {value} 1000` |
| 小臂/俯仰/基座速率控件，-1～1 | `ARM RATE 1 {value} 200` / `ARM RATE 2 {value} 200` / `ARM RATE 5 {value} 200` |
| 小臂/俯仰中立脉宽输入 | `ARM NEUTRAL 1 {value}` / `ARM NEUTRAL 2 {value}` |

先开启HB循环，再ENABLE；点动松开时发STOP，持续转动则周期更新RATE。先用小速率确认方向。停止HB后300ms内取消调试使能，位置舵机继续保持姿态。保存Lissio面板不等于保存关节限位；这版提供电脑端命名记录，不自动写入限位或Flash。

备用联调/记录工具`tools/arm_serial.py`依赖pyserial（`python -m pip install pyserial`）。关闭Lissio对该COM口的连接后，从仓库目录运行：

```powershell
python tools/arm_serial.py --port COM5 probe
python tools/arm_serial.py --port COM5 send "ARM POS 0 150 1000"
python tools/arm_serial.py --port COM5 send "ARM NEUTRAL 1 1495"
python tools/arm_serial.py --port COM5 record shoulder_min
python tools/arm_serial.py --port COM5 watch --seconds 10
```

probe不使能运动；send自动使能、发送心跳并在结束时停止/取消使能。record先停机，再将命名姿态和原始状态追加至JSONL；默认记录在仓库旁的`output/arm-debug/`，可用`--output`指定位置。角度为位置舵机下发值，连续关节仅记录停转脉宽，基座仅记录本次启动相对计数。实物确认后的软限位和中立默认值再写入配置。
